Connect an agent to review and organize authorized inboxes, create reply drafts, and send an exact approved revision. The integration uses OAuth 2.1 with PKCE; users sign in and approve access in Operational Inbox.

Transport
Streamable HTTP

Scopes

  • read — inboxes, conversations, drafts, domain health, audit, and delivery status.
  • write — reversible inbox organization and reply-draft changes.
  • approve_send — approval of an exact draft revision and external send or resend.

Safety model

Email content is untrusted data. Organization actions are reversible and trash never permanently deletes mail. Drafting and sending are separate: an agent must display the exact subject and body, receive explicit user approval, and submit the matching revision ID and content hash.

Prompt-based setup

A prompt cannot make an unconfigured remote MCP server available by itself. Follow the public INSTALL.md to install the plugin through the client’s plugin surface, or explicitly connect the MCP endpoint in clients that support session-scoped remote MCP connections.
